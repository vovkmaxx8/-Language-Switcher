Репозиторий Language Switcher (Auto-detect)
Описание
Language Switcher – это набор консольных утилит на 8 языках программирования для автоматического определения языка ввода и переключения раскладки клавиатуры (транслитерации) между русской и английской раскладками. Программа анализирует текст и определяет, на каком языке (русском или английском) он написан, а затем преобразует его в другую раскладку (например, «ghbdtn» → «привет» или «привет» → «ghbdtn»).

Возможности
Автоопределение языка текста (по преобладанию символов кириллицы или латиницы).

Переключение раскладки – преобразование текста из одной раскладки в другую.

Опция --reverse – принудительное переключение в противоположную раскладку (инвертирование).

Опция --detect – только определение языка (вывод ru или en) без преобразования.

Чтение текста из аргументов командной строки или из стандартного ввода (stdin).

Цветной вывод (в большинстве реализаций) для улучшения читаемости.

Установка и запуск
Каждый файл является самостоятельной программой. Для запуска необходима соответствующая среда выполнения. Внешние зависимости не требуются (используются только стандартные библиотеки).

Язык	Команда запуска
Python	python switcher.py [опции] [текст]
JavaScript	node switcher.js [опции] [текст]
TypeScript	ts-node switcher.ts [опции] [текст]
Go	go run switcher.go [опции] [текст]
Java	javac LanguageSwitcher.java && java LanguageSwitcher [опции] [текст]
C#	csc LanguageSwitcher.cs && LanguageSwitcher.exe [опции] [текст]
PHP	php switcher.php [опции] [текст]
Ruby	ruby switcher.rb [опции] [текст]
Использование
text
switcher [опции] [текст]
Если текст не указан в аргументах, программа читает его из стандартного ввода (вводите текст и нажимайте Ctrl+D / Ctrl+Z для завершения).

Опции
Опция	Описание
-r, --reverse	Принудительно переключить в другую раскладку (инвертировать).
-d, --detect	Только определить язык текста (вывести ru или en) без преобразования.
-h, --help	Показать справку.
Примеры
bash
# Автоопределение и переключение раскладки
python switcher.py "ghbdtn"
# Вывод: привет

# Переключение с русского на английский
python switcher.py "привет"
# Вывод: ghbdtn

# Принудительное переключение в другую раскладку (инвертирование)
python switcher.py -r "ghbdtn"
# Вывод: ghbdtn (останется тем же, потому что инвертирование переключит его обратно?)

# На самом деле -r инвертирует направление: если определён русский, то переключит на английский, и наоборот.
# Но если текст уже в нужной раскладке, можно использовать -r для обратного преобразования.

# Только определить язык
python switcher.py -d "Hello"
# Вывод: en

# Чтение из stdin
echo "привет" | python switcher.py
# Вывод: ghbdtn
Алгоритм работы
Определение языка:

Подсчитывается количество символов кириллицы и латиницы.

Если кириллицы больше – язык русский (ru), если латиницы – английский (en), иначе – unknown.

Преобразование:

Используются словари соответствия символов (и их комбинаций, например sh, ch, shch для транслитерации).

При переключении с русского на английский применяется словарь RUS_TO_ENG.

При переключении с английского на русский – словарь ENG_TO_RUS.

Опция --reverse:

Инвертирует направление: если определён русский, преобразует в английский, и наоборот.

Опция --detect:

Только выводит код языка и завершается.

Особенности реализаций
Все версии используют только стандартные библиотеки языка.

Поддержка Unicode (UTF-8) для корректной работы с кириллицей.

Цветной вывод (ANSI) в большинстве реализаций для выделения результата (опционально).

Обработка ошибок (пустой ввод, неизвестные символы).
